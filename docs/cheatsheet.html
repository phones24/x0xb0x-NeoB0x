Panel and modes

16 selector positions

1 - PATTERN / SYNC OUT ↓Patterns, internal tempo, and MIDI/DIN clock output.
2 - PATTERN / DIN SYNC ↓Patterns driven by DIN Sync input.
3 - PATTERN / MIDI SYNC ↓Patterns driven by MIDI clock, with MIDI performance control.
4 - PATTERN / EDIT ↓Create patterns and edit them step by step or live.
5 - TRACK / SYNC OUTUnsupported
6 - TRACK / DIN SYNCUnsupported
7 - TRACK / MIDI SYNCUnsupported
8 - TRACK / EDITNot Track Edit: this is a hazardous DAC/output test.
9 - COMPUTER CONTROLButton/LED test; USB remains active in every mode.
10 - BOOTLOAD ↓Enter the bootloader at power-on only.
11 - USER C ↓Persistent firmware settings.
12 - USER B ↓Pattern Edit with DIN Sync input.
13 - USER A ↓Pattern Edit with MIDI clock input.
14 - KEYBOARD ↓Play from the panel and send MIDI notes.
15 - RANDOM ↓Autonomous random noodling performance.
16 - MIDI PLAY ↓Play the synthesizer directly from MIDI, bypassing the sequencer.

Tempo Parameters

Change a tempo parameter

In any Pattern Play mode, press the TEMPO knob. The TEMPO LED stays lit, and the 1–16 LEDs show the current value.

Next, press the key for the parameter you want to change in the table below. Then turn the TEMPO knob to adjust it. To change something else, press its key and turn the knob again.

Press the knob once more, or move BANK, when you are finished.

Parameter presets

A preset is a saved snapshot of all ten parameters in the table above. It lets you bring back a complete variation and timing setup without adjusting every value again.

There are seven preset slots, shared by all patterns, and they remain saved after power-off. Set the parameters the way you want, then hold DONE and press a white key from 1 to 7 to save them. To recall that setup later, open Tempo Parameters and press the same white key on its own.

CombinationAction
CHAIN (tap)Tap tempo.
1–7Load that preset. Its values take effect immediately.
DONE + 1…7Save the current ten parameter values to that preset slot.
C'Reset probabilities and swing to 0, gate to 18, and the range to steps 1–16.

BPM is not part of a preset. Loading normally replaces all ten parameter values. To keep the current swing and gate length instead, enable MODE → USER C → page D# → white key 3.

Pattern Randomizer

Enter the randomizer

Start any Pattern Edit mode and press CHAIN. Press CHAIN again to return.

DONE also exits and immediately opens save-destination selection.

Hold low C, then press a white key. Selecting a scale does not change the pattern by itself.

D versus E: new setup or reused setup

Both keys generate a completely new pattern in the selected scale. They differ only in how they choose the randomizer setup. A setup is one of 13 internal probability profiles controlling note movement, rests, accents, slides, repeated sections, long notes, and other pattern structure. It is not a scale and it is not the generated pattern.

KeySetupResult and storage
DPick a new setup randomly from the 13 profiles.Generate a new pattern with that profile and the selected scale. The profile becomes the current setup in RAM, but D does not save it to EEPROM.
EReuse the current setup instead of picking another profile.Generate another new pattern with the same profile and selected scale. E also saves that profile to EEPROM, so it can be reused after power-up.

Typical workflow: press D until the generated style has the balance of notes, rests, accents, and slides you want. Then press E to keep making new variations with that same style. E does not replay the same notes; the random choices are rerolled while the probability profile stays fixed.

After power-up, E uses the last setup saved by E. If D has been pressed since power-up, E instead reuses and saves the setup chosen by the most recent D press.

MIDI

Play the synthesizer from MIDI

The sequencer is bypassed. BANK selects and stores MIDI input channel 1–16; Pattern / MIDI SYNC uses the same channel.

Out-of-range notes are octave-wrapped. Overlapping notes play legato with slide. Velocity 101–127 adds accent.

Note performance commands

MIDI inputAction
Notes 0–11No scale correction; note modulo 12 sets the root.
Notes 12–23Major-scale correction; modulo 12 sets the root.
Notes 24–35Minor-scale correction; modulo 12 sets the root.
36, 38, 40, 41/42, 43/44, 45/46, 47, 48Select pattern 1–8.
37 (C#)Stop trigger.
39 (D#)Toggle trigger latch.
49–96Transpose relative to MIDI note 60.

When the setting MODE → USER C → page D# → white key 1 is off, trigger notes start playback; releasing the last one stops it unless latch mode is active.

Controllers and Program Change

CC 1 sets gate length. For CC 2, 0–63 disables variations and 64–127 enables them. CC 123 sends all notes off and resets triggers.

Program Change 0–127 selects the bank and pattern, with eight programs per bank.

The setting MODE → USER C → page D# → white key 1 enables classic MIDI Start/Stop.

Keyboard

MIDI keyboard function

Sends MIDI notes.

The BANK knob sets the MIDI output address (channel). This address is stored permanently and is also used by other modes. The Step/Bank LEDs show the selected address whenever Keyboard mode is selected.

Random Mode

Autonomous random performance

The RANDOM MODE position immediately starts the internal clock and continuously generates random notes, accents, slides, and LED activity. The TEMPO encoder changes the speed.

This mode provides no pattern control and produces nothing that can be saved. Use Pattern Randomizer for editable generation.

User C Settings

Change settings

USER C is a MODE SELECT position that opens the settings. Black key C#, D#, or F# selects a page. White keys 1–8 toggle options.

A lit white-key LED means On. Each change is written to EEPROM immediately.

Bootloader

Enter the USB bootloader

  1. Switch off the power.
  2. Set MODE to BOOTLOAD.
  3. Power on and upload firmware with compatible software.
  4. To exit, power off, select another mode, and power on again.

Turning MODE to BOOTLOAD while the firmware is already running only idles the application; it does not start the bootloader.
